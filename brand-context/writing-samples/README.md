# Writing Samples

Save your writing examples here — one file per example. The `setup-brand-voice` skill reads this folder to build your voice profile.

**What to save here:**

- Emails you've sent to clients or your list
- Facebook or LinkedIn posts
- Long comments you've left in groups
- Newsletters
- Transcripts of voice notes or Looms
- Anything you wrote in your own words without heavy editing

**File format:** Plain text or markdown (`.md` or `.txt`). Name files descriptively:

```
email-welcome-sequence.md
fb-post-nov-2025.md
newsletter-jan-2026.md
loom-transcript-onboarding.md
```

**One file per example.** Don't combine multiple pieces into one file — the skill reads them individually.

**Minimum 5 examples** for a solid voice profile. More is better. The most natural, unedited writing gives the best results.

---

You can add files here directly (paste in or save from your computer), or paste examples into Claude and let the setup skill save them for you.
