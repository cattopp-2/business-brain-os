# Testimonials

Save your client and customer testimonials here — one file per testimonial or source. The `setup-brand-stories` skill reads this folder to build your testimonials file.

**What to save here:**

- Screenshots of DMs, comments, or messages (save as text — copy the words)
- Testimonials from intake forms or post-programme surveys
- Email feedback from clients
- Comments from Facebook groups or posts
- Google or other platform reviews
- Results your clients have shared publicly

**File format:** Plain text or markdown (`.md` or `.txt`). Name files so you know who and what:

```
testimonial-jane-membership-result.md
dm-feedback-sales-page.md
facebook-comment-nov-2025.md
email-reply-launch-result.md
```

**One source per file** where possible — makes it easier to find and reference later.

**You can add files here directly**, or paste testimonials into Claude and let the setup skill save them for you.

Testimonials in this folder feed into `brand-context/testimonials.md` — the compiled file that copy skills draw from when they need social proof, a result, or a client quote.
