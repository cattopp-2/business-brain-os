# brand-context/

This folder holds all the audience and brand intelligence that powers the copy skills.

The `brand-voice` skill reads from here automatically once it knows which brand is active. The more complete these files are, the better every piece of copy will be.

---

## Files in this folder

| File | What goes here | How it gets populated |
|---|---|---|
| `icp.md` | Ideal customer profile — who they are, what they want, what they fear, their real language | Populated during onboarding from discovery call notes and client-provided research |
| `voice-profile.md` | Brand voice — how the client sounds, what to avoid, tone markers | Generated by running `mkt-brand-voice` from writing samples |
| `writing-examples.md` | 5–10 examples of the client's actual writing in their natural voice | Provided by the client (emails, posts, website copy) |
| `audience-language-[topic].md` | Real phrases and language from customers on a specific topic | One file per offer area or content topic — add as needed |

---

## Subfolders

| Subfolder | Purpose | How it gets populated |
|---|---|---|
| `about-me/` | Existing material about the client — bio, about page, LinkedIn summary | Client saves files here before running `setup-user-profile` |
| `writing-samples/` | Individual writing examples — one file per piece | Client saves files here, or `setup-brand-voice` saves pasted examples |
| `brand-stories/` | Individual brand stories — one file per story | Client saves files here, or `setup-brand-stories` saves pasted stories |
| `testimonials/` | Individual testimonials — one file per source | Client saves files here, or `setup-brand-stories` saves pasted testimonials |
| `00 Website/` | HTML files for sales pages, landing pages, and website content | Generated by sales page and website skills |
| `01 Brand Assets/` | Logos, headshots, icons | Provided by the client |

## Compiled files (generated by skills — do not edit manually)

| File | Source | Generated by |
|---|---|---|
| `writing-examples.md` | All files in `writing-samples/` | `setup-brand-voice` |
| `story-bank.md` | All files in `brand-stories/` | `setup-brand-stories` |
| `testimonials.md` | All files in `testimonials/` | `setup-brand-stories` |
