# Brand Stories

Save your brand stories here — one file per story. The `setup-brand-stories` skill reads this folder to build your story bank.

**What to save here:**

- Your origin story — why you started your business
- Turning point moments — decisions or events that shaped how you work
- Client transformation stories — what changed for someone after working with you
- Personal stories you've shared publicly (posts, newsletters, talks)
- Failures or hard lessons that became part of your approach
- "Behind the scenes" moments that show who you really are

**File format:** Plain text or markdown (`.md` or `.txt`). One story per file, named descriptively:

```
origin-story.md
client-story-jane-membership.md
the-day-i-nearly-quit.md
how-i-learned-about-audience-language.md
```

**You can add files here directly** (paste in or save from your computer), or paste stories into Claude and let the setup skill save them for you.

Stories in this folder feed into `brand-context/story-bank.md` — the compiled file that copy skills read when they need a story hook, an example, or a personal anecdote.
