# Business Brain OS

A ready-to-use AI marketing system built on Claude Code. Clone it once, personalise it with your voice and offers, and use it to generate social posts, emails, sales pages, SEO blogs, and more — all written in your own voice, for your own audience.

This is the install template for the **AI Business Accelerator**. The full setup walkthrough is inside the course.

---

## Prerequisites

- A **Claude Code** subscription (claude.ai/code)
- **GitHub Desktop** (desktop.github.com)

---

## Getting Started

### 1. Clone this repo

1. Open **GitHub Desktop**
2. Click **File → Clone repository**
3. Paste this URL: `https://github.com/cattopp-2/business-brain-os`
4. Choose where to save it on your computer
5. Click **Clone**

### 2. Open in Claude Code

1. Open the **Claude Code** desktop app
2. Click **File → Open folder**
3. Navigate to the folder you just cloned and open it

### 3. Get future updates

When new skills are added or existing ones improved:

1. Open **GitHub Desktop**
2. Click **Fetch origin** (top bar)
3. Click **Pull origin** if updates are available

That's it — your skills update automatically.

## What's Inside

- `.claude/skills/` — 57 skills covering content, SEO, email, sales pages, research, and more
- `context/` — blank template files Claude reads at every session start (USER.md, SOUL.md, etc.)
- `brand-context/` — where your voice profile, ICP, and audience language files live
- `offers/` — one file per offer you sell
- `CLAUDE.md` — the master instruction file loaded at every session start
- `.claude/SKILLS-CHEATSHEET.md` — quick reference guide to every skill

---

## First Steps (after cloning)

Run these four setup skills in order — they personalise the system to you:

1. `setup-user-profile` — writes your USER.md
2. `setup-north-star` — writes your strategy and revenue tracker
3. `setup-brand-voice` — generates your voice profile
4. `setup-icp` — builds your ideal customer profile

Just open Claude Code, type "run setup-user-profile", and follow the prompts.

## Your Files vs Cathy's Updates

When you pull updates from GitHub, only Cathy's files change — your personal files are never overwritten.

**Your folders (edit freely, never touched by updates):**
- `brand-context/` — your voice profile, ICP, audience language, and brand assets
- `source/` — your raw source material (transcripts, notes, recordings)

**Cathy's folders (updated regularly — don't edit these):**
- `.claude/skills/` — the skill library
- `context/` — session start templates
- `offers/` — offer reference files

If you stick to editing only `brand-context/` and `source/`, pulling updates will always be safe and conflict-free.
