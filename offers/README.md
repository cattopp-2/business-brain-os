# offers/

One file per offer. Each file gives the copy skills everything they need to write promotional content for that offer without asking basic questions every time.

---

## How to set up

1. Copy `offer-template.md` and rename it `offer-[offer-slug].md` (e.g. `offer-quiz-build.md`)
2. Fill in all sections — the more detail the better
3. Repeat for each offer

The skills will read these files automatically when they need offer details.
