# Learnings — value-bomb
Captured feedback from previous sessions. Read this before running the skill.

---

### 2026-05-18
- The post doesn't have to be one sentence. A strong story hook (Cathy's own real morning) can run to a few short paragraphs before the ask — more compelling than a single abstract line.
- Use Cathy's own results as proof rather than generic client outcomes. Specific and real beats polished and theoretical.
- ✅ checklist format works well for task lists in value bomb posts — visual, scannable, specific.
- The comment keyword should be memorable and tied to the asset (e.g. "STACK" for the morning stack).
- Build or plan the asset before posting so the DM conversation is ready the moment comments come in.
