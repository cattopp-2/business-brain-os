# SEO Page Rewriter — Setup Instructions

This gives you a skill inside Claude Code that reviews your page for SEO, suggests specific changes, then rewrites the page once you're happy with the suggestions.

---

## What you need

- Claude Code installed on your computer (the desktop app or the terminal version)

---

## Installation — Mac

1. Open Finder
2. Press **Cmd + Shift + G** and type `~/.claude` then press Go
3. You should see two folders inside: `skills` and `commands`  
   (If they don't exist, create them)
4. Copy the `seo-page-rewriter` folder into `skills`
5. Copy `seo-page-rewriter.md` into `commands`

---

## Installation — Windows

1. Open File Explorer
2. In the address bar, type `C:\Users\YourName\.claude` and press Enter  
   (replace YourName with your actual Windows username)
3. You should see two folders inside: `skills` and `commands`  
   (If they don't exist, create them)
4. Copy the `seo-page-rewriter` folder into `skills`
5. Copy `seo-page-rewriter.md` into `commands`

---

## How to use it

1. Open Claude Code
2. Type `/seo-page-rewriter` and press Enter
3. When prompted, paste in your page content and confirm your target keyword
4. Claude will review the page and suggest specific changes
5. Confirm which changes you're happy with
6. Claude rewrites the full page ready to copy into your website

---

## What it checks

- Meta title (length + keyword)
- Meta description (length + written to earn the click)
- H1 headline
- Subheadings (H2s)
- Opening paragraph
- Keyword use throughout the body
- Calls to action
- Content length
