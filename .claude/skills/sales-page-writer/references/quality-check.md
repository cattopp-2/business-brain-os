# Sales Page Quality Check

Run this check before delivering any sales page. Do not deliver until all boxes are ticked.

## Copy Quality
- [ ] Headline leads with a tangible goal — not the offer name or format
- [ ] CTA appears in the hero section
- [ ] Problem section names real, specific frustrations the reader would recognise
- [ ] Transformation section is concrete and specific — not vague or abstract
- [ ] Features/inclusions are written as fascinator bullets, not plain feature lists
- [ ] "Who this is for" and "who this isn't for" are both present (where applicable to offer type)
- [ ] Social proof is outcome-specific ("Three new clients in three weeks") not feeling-based ("I feel so supported!")
- [ ] About section is present or clearly marked as a placeholder
- [ ] FAQs address real objections relevant to this offer type

## Technical
- [ ] No em-dashes anywhere in the copy
- [ ] No banned words or phrases (see writing-rules.md)
- [ ] No plain benefit lists — all bullets use fascinator-bullet frameworks
- [ ] No false urgency or pressure tactics
- [ ] All placeholders clearly marked with [PLACEHOLDER — description]
- [ ] CTA has action + outcome, not just a vague label

## Brand Voice
- [ ] headline-creator skill used — user selected a headline before copy was written
- [ ] Brand voice quick check passed (see brand-voice skill)
- [ ] Reads like Cathy talking to someone she knows, not presenting to a crowd
- [ ] UK spelling throughout
